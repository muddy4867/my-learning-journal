# 기록의 서재

한국사 학습과 독서 기록을 함께 관리하는 개인용 웹앱입니다. 정적 사이트로 배포되며, 설정 전에는 브라우저 로컬 저장소에 기록합니다.

## 기능

- 시험 날짜와 D-day 설정
- 한국사 강의 링크와 학습 상태 기록
- 월별 학습·독서 통합 캘린더
- 기출 점수 기록과 추이 그래프
- 책 서재와 읽기 상태 관리
- 간단 메모, 필사, 서평 기록
- 학습·점수·독서 통계
- Firebase Google 로그인과 Firestore 기기 간 동기화 연결 코드

## Google 로그인 및 동기화 설정

1. Firebase 프로젝트를 만들고 웹 앱을 추가합니다.
2. Authentication에서 Google 로그인 제공업체를 켭니다.
3. Firestore Database를 생성합니다.
4. `firebase-config.js`의 빈 객체에 Firebase 웹 앱 설정을 입력합니다.
5. Firestore 규칙에 `firestore.rules` 내용을 적용합니다.
6. Firebase Authentication의 승인된 도메인에 버셀 배포 도메인을 추가합니다.

Firebase 설정 전에도 학습, 점수, 서재, 노트 기능은 사용할 수 있습니다. 그때의 데이터는 현재 브라우저에만 저장됩니다. 로그인 후에는 사용자별 Firestore 문서로 동기화합니다.

## 배포

Vercel에서 이 저장소를 연결하면 별도 빌드 명령 없이 정적 사이트로 배포됩니다. 출력 디렉터리는 프로젝트 루트입니다.
